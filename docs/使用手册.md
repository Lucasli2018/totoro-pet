## 第一章 认识 totoro-pet

### 1.1 它是什么

totoro-pet 是一个 DSH Web GUI 插件，在页面右下角悬浮一只手绘 SVG 龙猫「绒绒」。它有饱食、心情、精力三条状态和经验等级，会随时间自己"饿"和"累"；你可以喂食、抚摸、玩耍、哄它睡觉。它不占任务栏、不抢焦点，只在你想理它的时候理你。

技术上一句话概括：宿主半边（Node.js）负责养成数值与存档，浏览器半边负责把龙猫画出来，两边通过本机回环 HTTP 接口通信——所以**关掉页面不会丢档**，重开还在。

### 1.2 界面元素图解

桌宠默认停靠页面右下角（距边缘 24px），从上到下四个部分：

```
      ┌─────────────┐
      │  💬 气泡     │ ← 台词冒泡，约 3 秒自动消失
      ├─────────────┤
      │ Lv.3 ○○○    │ ← 状态条：等级徽章 + 饱食/心情/精力三根迷你条
      ├─────────────┤
      │   🐭 本体    │ ← 龙猫 SVG，按住可拖拽，点一下会回应你
      ├─────────────┤
      │ 🍎✋🎾💤📖⚙ │ ← 交互条：悬停本体时浮现
      └─────────────┘
```

| 区域   | 元素    | 说明                                                              |
| ---- | ----- | --------------------------------------------------------------- |
| 气泡   | 台词气泡  | 互动反馈 / 冷却拒绝 / 离线降级提示都会在这里说，显示约 3 秒                              |
| 状态条  | 等级徽章  | `Lv.N`，升级即时变化                                                   |
| 状态条  | 三根迷你条 | 粉=饱食、黄=心情、绿=精力；鼠标悬停状态条可看到精确数值（如 `饱食 72 · 心情 80 · 精力 45 · Lv.3`） |
| 宠物舞台 | 龙猫本体  | 约 96px 见方（可缩放 0.5×–2.0×）；待机时呼吸眨眼                                |
| 交互条  | 六个按钮  | 🍎喂食 / ✋抚摸 / 🎾玩耍 / 💤睡觉(☀️唤醒) / 📖图鉴 / ⚙设置；桌面端悬停本体才浮现，触屏设备常驻显示 |

> 弹层（图鉴/设置）支持按 `Esc` 或点击遮罩关闭。

## 第二章 安装与启用

### 2.1 前置要求

| 项目      | 要求                                      |
| ------- | --------------------------------------- |
| Node.js | ≥ 18（插件 `engines.node` 约束）              |
| DSH     | 已安装 `@deepseek-ai/dsh`，且能启动 Web GUI     |
| 浏览器     | 任意现代浏览器，访问 GUI 地址 http://127.0.0.1:3080 |

### 2.2 分步安装（本地 tgz）

以 Windows PowerShell 为例（命令行路径请替换为你的实际存放位置）：

1. **获取安装包**：仓库 F:\dsh\totoro-pet 已附带打包好的 `totoro-pet-0.1.0.tgz`（约 20 KB）。若需自行重新打包：
   
   ```powershell
   cd F:\dsh\totoro-pet
   npm pack          # 生成 totoro-pet-0.1.0.tgz
   ```

2. **安装到 web profile**：
   
   ```powershell
   dsh plugin --profile web add totoro-pet-0.1.0.tgz
   ```

3. **重启 dsh web**：在运行 dsh web 的终端按 `Ctrl+C` 停止，然后重新执行：
   
   ```powershell
   dsh web
   ```

4. **刷新页面**：浏览器打开 http://127.0.0.1:3080 并刷新，右下角出现龙猫即成功。

### 2.3 如何确认插件已加载

打开 Web GUI 的 **设置 → 插件** 分区，列表中出现 **totoro-pet** 即表示宿主半边加载成功；同时页面上能看到桌宠本体表示浏览器半边挂载成功。两者都满足才算完整启用。

### 2.4 重启方法

插件随 dsh web 进程一起运行。任何"改了配置不生效""宠物不见了"的场合，先试标准三连：

1. 终端 `Ctrl+C` 结束当前 dsh web；
2. 重新运行 `dsh web`；
3. 浏览器强刷页面（`Ctrl+F5`）。

## 第三章 基础交互

### 3.1 四个互动按钮

鼠标悬停龙猫本体，交互条浮现后点击：

| 按钮        | 效果            | 经验  | 限制                      |
| --------- | ------------- | --- | ----------------------- |
| 🍎 **喂食** | 饱食 +30        | +5  | 无限制                     |
| ✋ **抚摸**  | 心情 +10        | +2  | **冷却 10 秒**，期内点击会被拒绝并撒娇 |
| 🎾 **玩耍** | 精力 −15、心情 +15 | +8  | 结算后精力 < 15 时拒绝（太累了）     |
| 💤 **睡觉** | 进入睡眠          | —   | 幂等：已睡着再点无副作用            |
| ☀️ **唤醒** | 结束睡眠          | —   | 幂等：醒着再点无副作用             |

所有增益都会被夹在 0–100 区间内（满值继续喂也不会溢出浪费以外的事，就是不变了）。睡觉/唤醒不加经验。

### 3.2 点击闲聊 vs 拖拽

- 在本体上**按下并原地松开**（位移 < 4px）：算"戳一下"，它会扭一扭并冒一句闲聊台词；
- **按住拖动超过 4px**：进入拖拽模式，可以把它搬到屏幕任意角落（详见第五章）。
- 在状态条、按钮、气泡上按下不会触发拖拽/闲聊，放心操作。

### 3.3 气泡台词含义

气泡内容分四种来源，认出它们能帮你判断发生了什么：

| 类型      | 示例                                | 含义                             |
| ------- | --------------------------------- | ------------------------------ |
| 服务端口吻台词 | 「唔——橡果！最爱的橡果！（抱住啃）」               | 互动成功，服务端从对应类别台词库（每类 9 条）随机抽的回复 |
| 冷却拒绝台词  | 「唔……刚摸过嘛，歇一会儿再摸～」「（躲开）摸多了会秃的啦！」   | 抚摸 10 秒冷却中，本次未生效               |
| 太累拒绝台词  | 「呼啊……没力气了，让我睡一觉先……」「玩不动了嘛……先充点电？」 | 精力不足，玩耍被拒绝                     |
| 离线降级台词  | 带「（离线）/（本地）」字样，如「咔嚓咔嚓……（离线也吃得香）」  | 浏览器暂时联系不上宿主接口，先本地演一下（此时数值不会变化） |
| 闲聊台词    | 「（歪头看你）」「今天也要加油鸭！」等 6 条           | 戳一下本体的回应                       |

## 第四章 养成系统详解

### 4.1 三维状态

饱食（hunger）、心情（mood）、精力（energy）取值均为 **0–100**，任何增减后都会夹回这个区间。初始值：饱食 80 / 心情 80 / 精力 100。

### 4.2 时间衰减

龙猫是活的——**每过一小时**按下面的速率线性衰减（读档和交互前统一结算，精确到小数小时）：

| 属性  | 清醒时       | 睡眠中              |
| --- | --------- | ---------------- |
| 饱食  | −0.8 / 小时 | −0.4 / 小时（减半）    |
| 心情  | −0.5 / 小时 | −0.25 / 小时（减半）   |
| 精力  | −1.5 / 小时 | **+12 / 小时（回充）** |

要点：

- **结算基于时间戳而非在线时长**：晚上合上笔记本，第二天回来它会实打实地饿了相应时长（精力除外——睡着的话反而回满了）。
- 例：清醒放置 10 小时 ≈ 饱食 −8、心情 −5、精力 −15；睡 8 小时 ≈ 精力 +96（上限 100 截断）。
- 衰减本身不产生台词、不加经验、不影响等级。

### 4.3 经验与等级

| 行为             | 经验  |
| -------------- | --- |
| 喂食 feed        | +5  |
| 抚摸 pet         | +2  |
| 玩耍 play        | +8  |
| 睡觉 / 唤醒 / 自然衰减 | +0  |

经验无上限，等级实时推导：``level = floor(exp / 50) + 1``。

| 等级   | 所需累计经验        |
| ---- | ------------- |
| Lv.1 | 0 – 49        |
| Lv.2 | 50 – 99       |
| Lv.3 | 100 – 149     |
| …    | 每 50 点升一级，无上限 |

### 4.4 睡觉机制

- 点 💤 后 `sleeping = true`，形象切换为闭眼歪头 + Zzz 动画；
- 睡眠期间精力 +12/小时回充，饱食/心情衰减减半——**睡前没电，睡醒满血**是正常现象；
- 睡觉时依然可以喂食/抚摸/玩耍（服务端不拦截），但玩耍照样扣精力，等于边充边耗，量力而行；
- 点 ☀️ 唤醒即结束睡眠，两个动作都幂等。

### 4.5 拒绝逻辑（它的小脾气）

| 规则           | 触发条件           | 表现                               |
| ------------ | -------------- | -------------------------------- |
| too-tired    | 玩耍前结算精力 < 15   | 返回错误 `too-tired`，气泡抱怨，**数值不变**   |
| pet cooldown | 距上次成功抚摸 < 10 秒 | 返回错误 `pet cooldown`，气泡撒娇，心情/经验不加 |

## 第五章 个性化设置

### 5.1 拖拽移动与位置记忆

- 按住龙猫本体即可拖动（交互条/状态条上按住无效），松手位置立即保存；
- 位置存在浏览器 `localStorage` 键 **`totoro-pet:pos`**，换页签、刷新都在；
- 拖不出屏幕：始终夹在窗口内（四周留 8px 边距）；缩小窗口时也会自动弹回可视区。

### 5.2 设置弹层

交互条点 **⚙ 设置** 打开设置卡片，共四项，全部**即时生效**：

| 设置项    | 形式  | 范围                           | 默认    | 说明                                |
| ------ | --- | ---------------------------- | ----- | --------------------------------- |
| 启用桌宠   | 开关  | 开 / 关                        | 开     | 关闭后整只消失，原位只剩一颗半透明**小圆点**，点圆点即恢复   |
| 大小     | 滑杆  | 0.50× – 2.00×（步长 0.05）       | 1.00× | 基准形象约 96px 见方                     |
| 不透明度   | 滑杆  | 30% – 100%（步长 5%）            | 100%  | 整体透明度                             |
| 闲置自动隐藏 | 数字框 | 0 – 480 分钟（步长 5，**0 = 不隐藏**） | 0     | 距最后一次互动超过设定分钟数后自动缩成小圆点；每 15 秒检查一次 |

被停用或自动隐藏时的小圆点悬停有文字提示，单击即可唤醒（停用状态下点击会同时重新启用）。

### 5.3 配置存储位置

- 外观偏好保存在浏览器 `localStorage` 键 **`totoro-pet:config`**（JSON）；
- 同时尽力同步一份到服务端（失败静默，不影响使用）：首次挂载时若本机没有配置则采用服务端的，若有则以本机为准反向推送；
- 因此换浏览器/清站点数据后，外观可能回到另一份配置——这是设计使然，不是丢档（养成进度永远在服务端，见第七章）。

## 第七章 进阶

本章面向想脚本化操控龙猫的进阶用户。所有接口**仅限本机回环访问**（127.0.0.1 / ::1），外部来源一律 403。

### 7.1 HTTP API 总表

Base URL：`http://127.0.0.1:3080/api/totoro-pet`。响应统一为 JSON：成功 `{ok:true,...}`，失败 `{ok:false,error:"..."}`。

| 方法   | 路径          | 用途                                                               | 其他方法命中 |
| ---- | ----------- | ---------------------------------------------------------------- | ------ |
| GET  | `/state`    | 查询状态（先结算衰减再返回）                                                   | 405    |
| POST | `/interact` | 执行交互，请求体 `{"type":"feed"                                         | "pet"  |
| GET  | `/config`   | 读取配置                                                             | —      |
| POST | `/config`   | 部分更新配置（仅接受 enabled/scale/opacity/autoHideMinutes 四键，类型或范围非法 400） | —      |
| POST | `/reset`    | 养成状态归零（配置不受影响）                                                   | 405    |

其他未知路径返回 404；请求体上限 64 KB（65536 字节），超出 413。

### 7.2 调用示例

PowerShell（Windows 推荐）：

```powershell
# 查询状态
Invoke-RestMethod http://127.0.0.1:3080/api/totoro-pet/state

# 喂食
Invoke-RestMethod -Method Post -ContentType "application/json" `
  -Body '{"type":"feed"}' http://127.0.0.1:3080/api/totoro-pet/interact

# 关闭闲置自动隐藏（部分更新）
Invoke-RestMethod -Method Post -ContentType "application/json" `
  -Body '{"autoHideMinutes":0}' http://127.0.0.1:3080/api/totoro-pet/config

# 重置养成状态
Invoke-RestMethod -Method Post http://127.0.0.1:3080/api/totoro-pet/reset
```

cmd / curl：

```bat
curl http://127.0.0.1:3080/api/totoro-pet/state
curl -X POST -H "Content-Type: application/json" -d "{\"type\":\"feed\"}" http://127.0.0.1:3080/api/totoro-pet/interact
```

响应示例（interact 成功）：

```json
{
  "ok": true,
  "state": {
    "hunger": 100, "mood": 85, "energy": 92,
    "exp": 13, "level": 1, "sleeping": false,
    "lastTick": 1755912000000,
    "recentEvents": [
      { "ts": 1755912000000, "type": "feed", "message": "唔——橡果！最爱的橡果！（抱住啃）" }
    ]
  },
  "message": "谢谢投喂～毛球消化中……"
}
```

### 7.3 错误码汇总

| 场景                         | 状态码 | error 字段                                        |
| -------------------------- | --- | ----------------------------------------------- |
| 来源非回环                      | 403 | `forbidden`                                     |
| 方法不符（见总表）                  | 405 | `method-not-allowed`                            |
| 未知路径                       | 404 | `not found`                                     |
| 请求体 > 64KB                 | 413 | `payload-too-large`                             |
| JSON 解析失败 / 请求体不是对象        | 400 | `invalid-json` / `invalid-body`                 |
| interact 缺 type / type 不认识 | 400 | `unknown-type`                                  |
| 抚摸冷却期                      | 400 | `pet cooldown`                                  |
| 精力不足玩耍                     | 400 | `too-tired`                                     |
| config 未知键 / 类型或范围非法       | 400 | `invalid-config-key:<键>` / `invalid-config:<键>` |
| 未捕获异常                      | 500 | `internal-error`                                |

### 7.4 状态文件结构

全部数据落盘在一个 JSON 文件里：

- 本机实际路径：`D:\tools\.dsh\storages\totoro-pet\state.json`
- 通用形式：`%DSH_HOME%\storages\totoro-pet\state.json`（未设置 `DSH_HOME` 环境变量时回退 `~/.dsh/storages/totoro-pet/state.json`，Windows 即 `C:\Users\<用户名>\.dsh\…`）

```json
{
  "state": {
    "hunger": 80,
    "mood": 80,
    "energy": 100,
    "exp": 0,
    "level": 1,
    "sleeping": false,
    "lastTick": 1755900000000,
    "lastPetAt": 0,
    "recentEvents": []
  },
  "config": {
    "enabled": true,
    "scale": 1,
    "opacity": 1,
    "autoHideMinutes": 0
  }
}
```

字段备注：`lastTick` 为上次衰减结算时刻（epoch 毫秒）；`lastPetAt` 为内部冷却字段，只存盘、不出现在任何接口响应中；`recentEvents` 记录最近 20 条生效交互（最新在前），超出丢弃最旧。写入采用临时文件 + 原子改名，重启 dsh web 后保留。

### 7.5 手动重置

两种方式任选：

1. **接口重置**（推荐，不用停服）：`POST /api/totoro-pet/reset` —— 状态回到初始值（80/80/100、0 经验、清醒），配置保持不变；
2. **删文件重置**：退出 dsh web → 删除 `D:\tools\.dsh\storages\totoro-pet\state.json` → 重启。文件缺失时自动以默认值重建（见第八章自愈说明）。

## 第八章 故障排查

| 症状                   | 可能原因                | 处理                                                        |
| -------------------- | ------------------- | --------------------------------------------------------- |
| 页面上没有宠物              | 插件未安装 / 未重启         | 按第二章重装并重启 dsh web                                         |
| 〃                    | 已停用或触发了闲置自动隐藏       | 看右下角有没有半透明**小圆点**，单击恢复                                    |
| 〃                    | 页面缓存了旧版 shell       | `Ctrl+F5` 强刷                                              |
| 设置→插件里找不到 totoro-pet | add 未成功或 profile 不对 | 确认命令用了 `--profile web`；重新执行 add 并看终端报错                    |
| 交互气泡带「（离线）/（本地）」字样   | 浏览器半边连不上宿主路由        | 确认是通过 http://127.0.0.1:3080 访问的 GUI（接口仅回环可达）；刷新页面重试       |
| 抚摸没反应还挨怼             | 10 秒冷却中             | 等 10 秒再摸，属正常游戏规则                                          |
| 玩耍被拒绝                | 精力 < 15             | 先 💤 睡一觉回充精力                                              |
| 数值明显不对劲              | 存档文件损坏              | **无需手动处理**：读取坏档时自动降级为默认值继续服务（自愈），下次保存即写回健康档案              |
| 想从头养                 | ——                  | 见 7.5 手动重置（POST reset 最省事）                                |
| 各种怪象反复出现             | ——                  | 标准三连：重启 dsh web → `Ctrl+F5` → 仍异常再看浏览器控制台（F12）有无红色报错，截图反馈 |

补充说明：

- 浏览器半边的挂载失败策略是"只警告、不打崩"：即使桌宠挂载出问题，控制台只会出现 `[totoro-pet]` 开头的 warn，GUI 其余功能完全不受影响。
- 宿主半边读写存档的任何异常同样只降级、不抛错，不会拖垮 dsh web。

## 第九章 卸载与数据清除

### 9.1 临时停用（不卸载）

只是暂时不想看到它：⚙ 设置 → 关闭「启用桌宠」。偏好与进度全部保留，随时一键恢复。

### 9.2 彻底卸载

1. 在运行 dsh web 的终端按 `Ctrl+C` 退出；

2. 删除插件目录（本机实际路径，通用形式 `<DSH_HOME>\profiles\web\node_modules\totoro-pet`）：
   
   ```powershell
   Remove-Item -Recurse -Force D:\tools\.dsh\profiles\web\node_modules\totoro-pet
   ```

3. 若重启后 GUI「设置 → 插件」仍列出 totoro-pet，打开 `D:\tools\.dsh\profiles\web\cordis.patch.yml` 检查是否残留 `totoro-pet` 注册条目，删除对应行后再重启；

4. 重启 `dsh web` 并刷新页面确认消失。

> 若你的 dsh 版本的 `dsh plugin --help` 列出了 remove/uninstall 类子命令，优先用它；本手册编写时实测该帮助在本机无输出，故给出上述手动步骤（适用于任何版本）。

### 9.3 数据清除

卸载插件不会自动删除养成数据，按需清理：

| 数据             | 位置                                                                                        | 清除方法                                         |
| -------------- | ----------------------------------------------------------------------------------------- | -------------------------------------------- |
| 养成进度 + 服务端配置副本 | `D:\tools\.dsh\storages\totoro-pet\state.json`（通用：`%DSH_HOME%\storages\totoro-pet\` 整个目录） | 删除文件或整个目录                                    |
| 位置记忆 + 外观偏好    | 浏览器 localStorage 键 `totoro-pet:pos`、`totoro-pet:config`                                   | GUI 页面按 F12 → Console 执行下方两条命令，或在浏览器"清除站点数据" |

```js
localStorage.removeItem('totoro-pet:pos');
localStorage.removeItem('totoro-pet:config');
```

三者全清 = 这只龙猫从你的世界里彻底路过了一遍。

## 附录 FAQ

**Q1：它会不会挡住我点页面？**
不会。桌宠层挂在全局覆盖槽位上，只有龙猫本体那一小块接收鼠标事件，其余区域照常点击穿透。

**Q2：关掉浏览器标签页，进度会丢吗？**
不会。所有养成数据存在服务端的 state.json 里，重开页面原样接续；甚至关着页面它也在按小时衰减（睡着则在回血）。

**Q3：开多个标签页会刷出多只龙猫吗？**
每个标签页各渲染一只，但共享同一份服务端状态——在这边喂了，那边刷新也能看到饱食上涨。多实例渲染互不干扰。

**Q4：换一个浏览器，进度还在吗？**
养成进度在（跟着服务端走）；但位置和外观偏好跟浏览器 localStorage 走，新浏览器会采用其本地值或服务端默认。

**Q5：最高多少级？练到满要多久？**
无上限。每 50 点经验升一级：纯喂食约 10 次/级，玩耍收益最高（+8/次，但要留意精力）。

**Q6：为什么我摸它没反应？**
大概率在 10 秒冷却里，气泡会撒娇提醒；如果气泡带「（离线）」字样则是接口没连通，见第八章。

**Q7：睡觉的时候能喂它吗？**
能。睡眠只是改变了衰减速率，服务端不禁止任何互动。不过玩耍照样扣精力，别边充边耗。

**Q8：我想让它开机自启怎么办？**
totoro-pet 随 dsh web 运行，让 dsh web 自启即可（如注册为计划任务/服务）；本插件自身无常驻进程。

**Q9：数据安全吗？会不会上传到哪里？**
所有数据只落在你本机：服务端文件在 DSH_HOME 下，偏好在本机浏览器里。HTTP 接口仅监听回环地址，外部机器无法访问。
